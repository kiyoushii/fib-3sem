# KIYOUSHII

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Учебный HTML/CSS-проект интернет-магазина винтажной и редкой одежды.

## Структура

- `index.html` — главная страница;
- `catalog.html` — каталог товаров, 9 категорий;
- `product.html`, `product-*.html` — страницы отдельных товаров (12 товаров);
- `about.html` — о магазине;
- `contacts.html` — контакты;
- `js/main.js` — открытие/закрытие модального окна заявки, валидация формы;
- `css/style.css` — общие стили;
- `images/` — изображения проекта.

## Технологии

HTML5, CSS3, минимальный JavaScript (модальное окно).

## Как посмотреть

Открыть `index.html` в браузере или перейти по ссылке ниже.

## Демо

https://kiyoushii.github.io/fib-3sem/

## Обязательные страницы

- Главная (`index.html`) — hero-блок, категории, популярные товары, преимущества;
- Каталог (`catalog.html`) — карточки товаров по категориям, блок фильтров;
- Карточка товара (`product-*.html`) — галерея фото, описание, таблица размеров или характеристик, кнопка заявки;
- Заявка — реализована как модальное окно (`<dialog>`), открывается с любой карточки товара;
- Контакты (`contacts.html`) — форма обратной связи.

## Самостоятельные доработки

Сверх базового варианта из методических указаний сделано:

- вместо одной карточки товара — 12 товаров в 9 категориях, у каждого отдельная страница с галереей фото и таблицей размеров/характеристик;
- собственная визуальная концепция (цветовая палитра, типографика на Google Fonts) вместо стандартного оформления;
- блок "О магазине" с историей, принципами и статистикой — отдельная страница, не предусмотренная базовым заданием;
- хлебные крошки на всех внутренних страницах;
- якорные ссылки с других страниц на разделы главной (`index.html#advantages`, `index.html#popular`);
- блок фильтров на странице каталога как отдельная Grid-колонка (`catalog-layout` с `grid-template-areas`);
- модальное окно заявки с подстановкой выбранного товара, HTML-валидацией и сообщением об успешной отправке;
- кнопка "Наверх" (`position: fixed`);
- общие классы `.card`, `.btn`, `.img-cover`, `.section-title` вместо дублирования одинаковых стилей — меньше повторов в CSS;
- состояния `:hover`, `:focus-visible`, `:active`, `:disabled` на кнопках и ссылках.
