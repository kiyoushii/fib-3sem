# KIYOUSHII

Учебный HTML/CSS-проект интернет-магазина винтажной и редкой одежды.

## Структура

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `about.html` — о магазине;
- `contacts.html` — контакты;
- `product-*.html` — страницы отдельных товаров;
- `css/style.css` — общие стили;
- `images/` — изображения проекта.

## Технологии

HTML5, CSS3.
