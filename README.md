# ФиБ — трек изучения (3 семестр, фронтенд)

Курс "Фронтенд и бэкенд разработка". В этом семестре — 5 контрольных работ,
каждая продолжает предыдущую и наращивает стек.

## План

- [ ] **КР1** — `kr1-html-shop/` — многостраничный сайт на чистом HTML/CSS
- [ ] **КР2** — `kr2-bootstrap-shop/` — тот же сайт на Bootstrap
- [ ] **КР3** — `kr3-responsive-shop/` — адаптивная вёрстка + доступность
- [ ] **КР4** — `kr4-js-shop/` — интерактивность на чистом JS
- [ ] **КР5** — `kr5-spa-shop/` — SPA на React

Сквозной проект — интернет-магазин (товары, каталог, карточка товара, заявка/заказ).

## Как работаем

1. Разбор темы (коротко, с примерами) в чате.
2. Практика — код пишу сам, с подсказками и ревью.
3. Каждая КР — отдельная папка, отдельный git-репозиторий, публикация на GitHub Pages.
